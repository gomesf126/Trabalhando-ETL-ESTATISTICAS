#  Trabalhando com ETL, Estatística Descritiva e Dashboards

Repositório desenvolvido com foco em boas práticas de engenharia e análise de dados, automação de limpeza, análise estatística e visualização interativa utilizando **Python**, **Pandas**, **Plotly** e **Streamlit**.

O objetivo principal deste projeto é aplicar **programação defensiva** para garantir que pipelines de dados e dashboards lidem de forma robusta com "sujeiras" do mundo real (como valores nulos, dados ausentes e distorções por zeros inválidos).

---

##  O que você encontra aqui:

* **Tratamento de Dados Defensivo:** Funções blindadas contra entradas vazias (`None`, `empty`), valores nulos (`NaN`) e anomalias de negócio (preços zerados).
* **Indexação Booleana Avançada:** Filtros limpos e vetorizados no Pandas para higienização de séries.
* **Estatística Descritiva Modularizada:** Funções prontas para cálculo de variância, desvio padrão, mediana e quartis.
* **Dashboards Interativos:** Painéis visuais e dinâmicos desenvolvidos com **Streamlit** e gráficos interativos com **Plotly**.

---

## Tecnologias Utilizadas
* **Linguagem:** Python 3.x
* **Manipulação & Estatística:** Pandas, NumPy
* **Visualização & Dashboard:** Streamlit, Plotly
